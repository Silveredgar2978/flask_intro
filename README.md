# HTML/Flask AI Chatbot Website

built with python, just enter questions click the button beside and gemini will answer.

## What it does

- Takes input
- Sends it to Gemini API
- Returns an answer
- You can keep entering questions

## Requirements

- Python 3.10+
- Gemini API key (free tokens with gemini-2.5-flash)

## How to run 

1. Clone repo
2. Install dependencies:
    pip install -r requirements.txt
3. Make your .env , entering your Gemini API key in the .env, make sure its re-named ".env"
4. Run: app.py
